API_

Abierta, sin registro. Base URL https://licit.es/api/v1. Cubre la ventana reciente (últimos 12 meses); para el histórico completo usa el explorador o descarga los Parquet.

Para agentes

Todas las rutas devuelven JSON. Envía Accept: text/markdown (o añade ?formato=md) para recibir Markdown compacto, listo para un LLM.

curl -H 'Accept: text/markdown' \
  'https://licit.es/api/v1/buscar?q=ciberseguridad&limit=5'

POST /buscar

Texto libre (full-text en español, por prefijo) + filtros combinados con AND. Paginación con cursor_siguiente. También acepta GET con los mismos campos como query string.

curl -X POST https://licit.es/api/v1/buscar \
  -H 'Content-Type: application/json' \
  -d '{
    "q": "mantenimiento ascensores",
    "filtros": {
      "tipo_contrato": ["Servicios"],
      "estado": ["En plazo"],
      "cpv_prefijo": "50",
      "importe_min": 50000,
      "importe_max": 500000,
      "fecha_publicacion_desde": "2026-01-01",
      "ccaa": "Madrid",
      "organo": "Ayuntamiento",
      "adjudicatario": "Indra",
      "financiacion_ue": true
    },
    "ordenar": "fecha",
    "limit": 20
  }'

ordenar: fecha (por defecto), importe o relevancia (solo con q). limit hasta 100.

Rutas

MétodoRutaDescripción
POST/buscarBúsqueda con filtros y cursor
GET/licitacion/{id}Ficha de una licitación (UUID o nº de expediente)
GET/empresa/{nif}Adjudicaciones, importes, baja media, CPV y órganos frecuentes
GET/organo/{id}Licitaciones del órgano, adjudicatarios frecuentes
GET/similares/{id}Mismo CPV e importe parecido
GET/catalogos/{tipo}Valores válidos: tipo_contrato, estado, procedimiento, tramitacion, organo_tipo, cpv
GET/saludEstado y fecha de la última sincronización

Datos abiertos

GET /data/index.json lista los ficheros Parquet publicados (licitaciones, lotes, adjudicaciones, CPV y empresas). Se pueden leer directamente con DuckDB, Polars o pandas:

duckdb -c "SELECT tipo_contrato, count(*)
  FROM 'https://licit.es/data/parquet/reciente/licitacion.parquet'
  GROUP BY 1 ORDER BY 2 DESC"
