licit

API estructurada de licitaciones públicas de España. Búsqueda, filtrado e inteligencia competitiva sobre datos de la PLACSP.

Documentación Código fuente

Qué ofrece

  • Búsqueda full-text en español con filtros por CPV, NUTS, tipo de contrato, estado, importe y más
  • Detalle completo de cada licitación: criterios de adjudicación, requisitos de solvencia, lotes y documentos
  • Perfiles de órganos y empresas con estadísticas de contratación, importes y CPV frecuentes
  • Inteligencia competitiva: licitaciones similares, estadísticas de precios y adjudicatarios frecuentes
  • Respuestas para agentes: JSON denso o Markdown por negociación de contenido, códigos CODICE resueltos a etiquetas legibles

Ejemplo

curl -X POST https://api.licit.es/api/v1/buscar \
  -H 'Content-Type: application/json' \
  -d '{"q": "desarrollo software",
       "filtros": {"tipo_contrato": ["Servicios"]},
       "limit": 5}'

Endpoints

MétodoRutaDescripción

GET/licitacion/{id}Detalle completo
GET/empresa/{nif}Perfil de empresa
GET/organo/{id}Perfil de órgano
GET/similares/{id}Licitaciones similares
GET/catalogos/{tipo}Valores válidos para filtros

Por qué licit

La PLACSP publica datos de contratación pública a través de feeds Atom sin capacidad de filtrado. Las alternativas existentes forman parte de planes enterprise de plataformas privadas. licit estructura estos datos en una API abierta, pensada para desarrolladores, analistas y agentes.

Stack

  • FastAPI + asyncpg + PostgreSQL 16
  • ETL incremental de feeds ATOM CODICE
  • Búsqueda con tsvector en español + pg_trgm
  • Docker Compose + Caddy
