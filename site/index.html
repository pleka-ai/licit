Qué hay

  • Búsqueda de texto en español con filtros por tipo, estado, CPV, importe, fechas, órgano y adjudicatario.
  • Perfiles de empresas y órganos: contratos, importes, baja media, CPV y contrapartes más frecuentes.
  • Licitaciones similares por CPV e importe.
  • Respuestas en JSON o en Markdown, para que un agente las lea tal cual. Los códigos CODICE llegan traducidos a etiquetas.
  • Todo el histórico en Parquet, para consultarlo con SQL en el navegador o descargarlo.

Ejemplo

curl -X POST https://api.licit.es/v1/buscar \
  -H 'Content-Type: application/json' \
  -d '{"q": "desarrollo software",
       "filtros": {"tipo_contrato": ["Servicios"]},
       "limit": 5}'

Por qué

La PLACSP publica los datos en feeds ATOM paginados, sin filtros ni búsqueda. licit los procesa cada día y los expone como API y como Parquet.

Cómo está hecho

Los datos se actualizan cada madrugada en GitHub Actions. La API responde desde la red de Cloudflare y el explorador ejecuta las consultas SQL en tu navegador.
