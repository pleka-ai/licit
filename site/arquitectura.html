De la PLACSP a tu consulta

  1. 1

    Fuente

    Los datos son los que publica la Plataforma de Contratación del Sector Público en sus feeds de licitaciones. licit no añade ni modifica información.

  2. 2

    Actualización diaria

    Cada madrugada se descargan las licitaciones nuevas y las que han cambiado y se reconstruye el modelo de datos: entidades (licitaciones, lotes, órganos, empresas, CPV, lugares, documentos, criterios…) y los hechos que las miden (presupuesto, adjudicaciones, tramitación, cambios de estado…). Los códigos CODICE se traducen a etiquetas legibles y cada licitación conserva su historial de estados.

  3. 3

    Publicación

    El resultado se publica en dos formatos: la API, para buscar y consultar fichas, y ficheros Parquet con todo el histórico, para análisis: el modelo de datos y, aparte, las tablas tal como las publica la PLACSP.

  4. 4

    Consulta

    La API responde desde la red de Cloudflare. En /explorar, las consultas SQL se ejecutan en tu navegador y no pasan por ningún servidor.

Para quien usa los datos

Frescura

Los datos se actualizan cada madrugada. Las respuestas de la API pueden tener hasta una hora de antigüedad respecto a la última actualización.

Identificadores estables

El id de cada licitación no cambia entre actualizaciones, así que se puede guardar y volver a consultar más adelante.

Formatos

La API responde en JSON, o en Markdown con Accept: text/markdown. Los códigos CODICE llegan traducidos a etiquetas.

Cobertura

Licitaciones publicadas desde 2017 en los perfiles de contratante de la PLACSP y en las plataformas autonómicas que agrega.

Modelo de datos

Los Parquet de parquet/modelo/ son entidades (licitacion, lote, organo, empresa, cpv, documento…) y hechos que las miden (ciclo_licitacion, presupuesto_lote, adjudicacion…), unidos por sus columnas _key, que no cambian entre actualizaciones. Su manifest.json describe cada tabla y sus columnas. En parquet/raw/ están las tablas tal como las publica la PLACSP.

Acceso abierto

Sin registro ni claves. La API, el explorador y los ficheros Parquet son de libre acceso.

Totales en búsquedas

El total de resultados es exacto hasta 10.000. Por encima, la API indica que es un mínimo (total_exacto: false).
